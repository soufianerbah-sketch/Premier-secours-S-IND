# لعبة الإسعافات الأولية · Jeu des premiers secours

SOMIPHOS – شركة مناجم الفوسفات

لعبة أسئلة وأجوبة اختيارية عن الإسعافات الأولية، بالعربية أو الفرنسية، في 4 مراحل متدرجة الصعوبة (مبتدئ، متوسط، متقدم، خبير).
Quiz à choix multiples sur les premiers secours, en arabe ou en français, 4 niveaux de difficulté croissante.

## التشغيل · Utilisation
افتح الملف `index.html` في أي متصفح. لا يحتاج إلى إنترنت ولا إلى تثبيت.
Ouvrez `index.html` dans un navigateur. Aucune installation, fonctionne hors ligne.

## النشر على GitHub Pages · Publication
1. أنشئ مستودعا جديدا على GitHub وارفع كل ملفات هذا المجلد.
2. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
3. يظهر الرابط بعد دقيقة: `https://<username>.github.io/<repo>/`

## تعديل الأسئلة · Modifier les questions
الأسئلة في آخر ملف `index.html` داخل المصفوفة `S` (4 مجموعات، لكل مرحلة مجموعة). في كل سؤال: العربية أولا ثم الفرنسية، والجواب الصحيح دائما أول خيار (يتم خلط الخيارات عند العرض).
